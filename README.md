# madebyskows

A professional static website for **madebyskows / Made by Skows LLC** — showcasing gameplay design, systems architecture, and indie game products.

**Live Site**: [madebyskows.com](https://madebyskows.com)

## Overview

This is a clean, responsive, dark-themed portfolio and product showcase built with **vanilla HTML, CSS, and JavaScript**. No frameworks or build tools required — just pure web standards.

### Key Features

- ✨ **Responsive Design**: Mobile-first layout with semantic HTML5
- 🎨 **Dark Theme**: Professional dark mode with excellent contrast and accessibility
- 📧 **Contact Form**: Integrated with [Formsubmit.co](https://formsubmit.co) for email forwarding
- ⚖️ **Legal Pages**: Global and product-specific Privacy & Terms templates
- 🔍 **SEO Ready**: Meta tags, semantic markup, proper heading hierarchy
- ♿ **Accessible**: ARIA labels, keyboard navigation, semantic HTML
- ⚡ **No Dependencies**: Pure HTML/CSS/JS — fast load times, no build step required
